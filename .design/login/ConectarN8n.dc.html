Cole a URL da sua instância e uma chave de API

A API pública do n8n não tem OAuth e não tem tela de login: ela autentica com a URL da instância mais uma chave pessoal, enviada no cabeçalho X-N8N-API-KEY. São esses dois campos — não existe botão “entrar com n8n” para eu te oferecer.

Instância e chave SEM CONEXÃO AINDA
Isto é uma leitura. Nada é alterado no n8n agora.

Instância própria (self-hosted) entra pelos mesmos dois campos — só a URL muda, algo como https://n8n.suaempresa.com. Não tem segundo formulário.

Onde eu acho essa chave
1

No n8n, abra Settings.

2

Dentro de Settings, escolha n8n API.

3

Clique em Create an API key e cole aqui — o n8n mostra a chave uma vez só.

O que a chave faz aqui

Lê fluxos e execuções. É disso que o painel inteiro é feito.

Escreve um caso só: o diff que apareceu nesta tela e você aprovou num clique — e o backup é salvo antes de ele ir.
